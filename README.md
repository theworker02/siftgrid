# siftgrid

Sift numeric grid values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/siftgrid/

## Install / run

```bash
git clone https://github.com/theworker02/siftgrid.git
cd siftgrid
node src/cli.js
node --test
```
